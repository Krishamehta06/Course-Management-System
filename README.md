# Course Management System

## 📌 Project Description

The Course Management System is a Python-based project used to manage and analyze course information.

It stores details such as course name, number of students, course duration, course fee, and average marks.

The project also performs statistical analysis and creates graphs to understand the course data easily.

## 🎯 Objectives

- Manage course information.
- Calculate total and average number of students.
- Analyze course fees and marks.
- Calculate total revenue for each course.
- Perform statistical analysis.
- Display course data using graphs.
- Provide an overall course summary.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- SciPy
- Matplotlib
- Bokeh

## 📊 Features

### 1. Course Details
The system stores:

- Course ID
- Course Name
- Number of Students
- Duration in Months
- Course Fee
- Average Marks

### 2. NumPy Analysis

The program calculates:

- Total students
- Average students per course
- Maximum students
- Minimum students
- Average course fee
- Highest course fee
- Lowest course fee
- Overall average marks

### 3. Pandas Analysis

The program finds:

- Course with maximum enrollment
- Course with highest average marks
- Course with highest fee

### 4. Revenue Calculation

The total revenue of each course is calculated using:

*Total Revenue = Students × Course Fee*

### 5. SciPy Statistical Analysis

The project performs:

- One-sample t-test
- Pearson correlation

The t-test checks whether the average marks are significantly different from 75.

### 6. Data Visualization

The project creates:

- Bar graph of students enrolled in each course
- Line graph of average marks
- Interactive Bokeh graph for course enrollment
